# iOS Simulator for Android Studio

Streams and controls the iOS Simulator in an Android Studio tool window, powered by a bundled
[Baguette](https://github.com/tddworks/baguette) (Apache-2.0).

Requires macOS on Apple Silicon and Xcode 26 (iOS 26 simulators).

Build: `./gradlew buildPlugin` (downloads the pinned Baguette release). Install the zip from `build/distributions` via
Settings > Plugins > Install Plugin from Disk.
